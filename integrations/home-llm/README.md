# Hassaniya for acon96/home-llm

[home-llm](https://github.com/acon96/home-llm) has two parts: the "Local LLM Conversation" Home Assistant integration, and the small fine-tuned "Home" models. It builds its training data from per-language CSV *piles*. This folder adds **Hassaniya** as a sixth language next to English, German, French, Spanish and Polish.

```
piles/hassaniya/              generated by scripts/export_home_llm.py from data/lexicon/lexicon.yaml
apply_prompting_patch.py      adds the "hassaniya" entries to home-llm's data/prompting.py (6 small dicts)
check_pile.py                 static check against home-llm's loader rules (headers, device types, responses per template)
```

## Use
```bash
git clone https://github.com/acon96/home-llm && cd home-llm/data
pip install -r requirements.txt
cp -r /path/to/Gg/integrations/home-llm/piles/hassaniya piles/
python3 /path/to/Gg/integrations/home-llm/apply_prompting_patch.py prompting.py
python3 generate_data.py --train --small --language hassaniya        # -> output/home_assistant_train.jsonl
# multilingual: --language hassaniya french   (French code-switching is common in Mauritania)
```
Then train with their Axolotl configs (`train/configs/*.yml`, e.g. gemma3-270m or a 1–3B base). Serve the result through their integration, or through Ollama with HA's built-in Ollama integration.

## Notes
- The phrasing follows our corpus-checked lexicon: **اگدي** (switch on), **طفّي**, **اگفل** (close/lock), the **حگل** softener, **ظرك** (now), and **اهيه** for acknowledgements. Replies use genderless first-person past tense ("گدّيت <device_name>"), because the pile format doesn't know a device's grammatical gender.
- `pile_of_specific_actions.csv` is intentionally header-only. home-llm derives those friendly names from ASCII ids, which would pair Arabic phrases with Latin names.
- Temperatures are Celsius only (`<temp_c>`).
- `check_pile.py` passes with 0 problems against the English pile headers. home-llm's own generator was **not executed here**, because this build environment doesn't run third-party code. Please run the command above once and report any error upstream or here.
- Consider sending the pile upstream as a PR to acon96/home-llm once native speakers have reviewed it.
